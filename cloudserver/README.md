# Cloud Server – Linux & Networking Tips
This folder is a personal knowledge base for everything related to **Linux servers**, cloud networking, and server management.  
It includes practical notes, security hardening guides, CLI tools, and scripts used in real-world cloud deployments.

## Topics Covered
- Linux command-line usage
- SSH, UFW, IPTables
- Nginx, systemd, and cron jobs
- VPS/server setup (Ubuntu, CentOS)
- Cloud VM/network setup (AWS EC2, GCP Compute, etc.)
