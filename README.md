# Long Nguyen's Technical Collections
Welcome to my personal repository of technical collections — a curated set of knowledge, tools, frameworks, and hands-on insights I’ve gathered throughout my journey as a Technical Lead and Software Architect. This is not just a storage space — it's a reflection of my continuous learning, problem-solving mindset, and passion for modern, scalable software engineering.

## Purpose of This Repository
This collection is designed to
- Help developers, technical leads, and architects quickly access best practices and real-world knowledge.
- Share architectural blueprints, patterns, and coding tips I've personally used or reviewed.
- Serve as a **portfolio of my mindset**, methodology, and experience in delivering scalable and maintainable systems.
- Push my **personal brand** in the tech ecosystem, especially around cloud-native architecture, backend at scale, and AI/LLM integration.

## What's Inside

| Section | Description |
|--------|-------------|
| `architecture/` | High-level system design, diagrams, microservices patterns, distributed transactions (Saga, CQRS), etc. |
| `ai-llm/` | Practical applications of LLMs (OpenAI, Claude) in software systems, automation, fine-tuning, RAG, etc. |
| `backend/` | Code snippets, best practices, and patterns using NestJS, Golang, Python, and more. |
| `devops/` | Infrastructure as Code (Terraform, GitHub Actions), Kubernetes manifests, CI/CD pipelines. |
| `saas/` | Scalable multi-tenant SaaS architecture with usage-based billing, isolation, and automation. |
| `notes/` | Quick notes, checklists, architecture decisions, cloud provider comparisons. |

> Most examples are based on AWS, Docker, Kubernetes, and modern service-based infrastructure.

As a software architect and technical leader, I’m often asked
